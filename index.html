Hangul Structure 101 for Gamers

Korean is an alphabet assembled into blocks. Every block consists of an Initial Consonant (Left Hand) + Medial Vowel (Right Hand) + optional Final Batchim (Left Hand).

Two-Part Block (Initial + Vowel)
ㄱ (r) + ㅏ (k) = 가 (ga)
Three-Part Block (Initial + Vowel + Batchim)
ㄱ (r) + ㅏ (k) + ㄴ (s) = 간 (gan)
Compound Batchim Block
ㄷ (e) + ㅏ (k) + ㄺ (f+r) = 닭 (dak)

🪟 Korean Keyboard Setup & Floating Screen Guide

How to install the Korean IME in Windows and how to make the on-screen keyboard float over your game window.

1

Step 1: Install Korean Language in Windows 10/11

1. Open Windows Settings (Press Win + I).
2. Go to "Time & Language" → "Language & Region".
3. Click "Add a language" and search for "Korean (한국어)".
4. Install the Basic Typing package.

Win + I > Time & Language > Add Language > Korean
2

Step 2: Switching Between English/Arabic & Korean

• Press Win + Space or Left Alt + Shift to toggle between your languages.
• When Korean is active, press the Right Alt key (한/영) to switch between English typing and Hangul typing (or click the "A" icon in the taskbar so it turns into "가").

Toggle Language: Win + Space | Toggle Hangul: Right Alt
3

Step 3: Make the Keyboard Float On-Screen

• Press Win + Ctrl + O to launch the Windows On-Screen Keyboard (OSK).
• You can drag it, resize it, and position it directly over or next to your MapleStory game window!
• Alternatively, click "🪟 Float Keyboard" on this website to test using a floating keyboard right now.

Launch Floating On-Screen Keyboard: Win + Ctrl + O
